# Fort-Hare-Courier-Logistics
A database-driven courier and logistics management system developed using C#, ASP.NET Web Forms and SQL.

An ongoing academic project developed as part of a Bachelor of Commerce in Information Systems at the University of Fort Hare.

## Project Overview

The Fort Hare Courier & Logistics Information System is a database-driven application designed to support courier and logistics operations.

The system is being developed to manage information relating to:

- Clients
- Parcels
- Deliveries
- Drivers
- Warehouses
- Payments
- Users and authentication

## Technologies

- C#
- ASP.NET Web Forms
- .NET Framework
- PostgreSQL
- SQL
- Visual Studio
- Git/GitHub

## Current Development

This project is currently in progress. Development includes database design, application functionality, authentication, role-based access and database connectivity.

## Purpose

The project provides practical experience in information systems development, relational database management, SQL, software development and technical problem-solving.
